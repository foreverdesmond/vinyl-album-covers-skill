# 默认画法与显式替换

## 默认：细腻半写实编辑插画

用户选定的基准是 `../assets/history/eason-16x9.jpg`（陈奕迅精选确认成品）的**绘制技法**。位置、人物、蓝紫粉配色、字体、唱片架、音箱与功放不是画法，不能继承。

特征：成年比例和可信透视；轮廓纤细、局部可弱化，不为每个物体包粗黑边；形体略有概括但有柔和丰富的明暗过渡；金属和盘片有克制的图形化高光；少量细腻印刷纹理。有插画手感和适度卡通化，不是实拍/3D产品渲染，也不是平涂漫画、幼儿卡通、粗线描或强排线。专辑素材和场景统一处理；品牌PNG不改画法。

默认通过上述文字传达，不将陈奕迅完整成品附入每次请求，防止复制颜色/陈设。确需校准时可查看它再提炼文字；用户明确要求附画法参考图时才作为仅画法参考附入，当前配色分区和场景清单仍优先。

## 参数独立与优先级

1. 明确的用户画风 > 本页默认画法。用户说“哥特风”“赛博朋克风”“奶油卡通风”等，视为有效画风输入，直接替换默认，不必再确认。
2. 主题独立：例如“万圣节主题”选择场景和物件，不自动切成粗线漫画或哥特画法。“万圣节主题，奶油卡通画风”则用后者作画法。
3. 配色独立：当前唱片配色仍是默认；仅画风名称不自动引入紫色、霓虹或奶油色全局调色。用户明确要风格典型配色或给出颜色时才覆盖，LOGO原色不变。
4. 解析后的本次画法写入设计计划和实际提示词；**替换**不兼容默认措辞，不把“柔和半写实”“2–4级平涂”“奶油3D”等矛盾指令拼在一起。
5. 无论画法如何替换，原封面只能保真转换媒介，不能重创内部图案；LOGO锁定、文字准确、字号/输出目录/双比例/ZIP规则仍生效。

风格词可由其形态、线条、光影、材质和字体表现。用户只给标签时合理补全，保持当前专辑识别，不要求额外问卷。
