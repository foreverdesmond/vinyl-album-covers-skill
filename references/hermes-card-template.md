# Hermes 黑胶封面卡模板

卡片建在黑胶封面设计工作区的「黑胶封面设计任务」项目里,状态 todo,不指定执行人,由管理员自动接单。不要直接派给设计师。

标题:`【黑胶封面】<歌手名> - <专辑名>`

```markdown
## 输入

- 唱片封面:见附件
- 专辑名:
- 封面可包含的元素:

## 可选

- 歌手名:没有歌手的专辑留空,不要写“无歌手”
- 唱片封面:默认先转简笔画;负责人授权直接用原封面时写“唱片封面:用原图”
- 样片曲目:默认第 1 首
- 不出图的曲目:无
- 样片审核:默认需要;负责人授权时写“跳过样片审核”
- 跳过样片审核时的出图时机:默认立刻做,也可写“定时做 <时间>”或“待定”

流程以 artifact-template-vinyl-album-covers 技能为准。
```

卡片里不要写画风、配色、字体或执行人,这些由技能决定。
