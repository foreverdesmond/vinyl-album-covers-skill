# 专辑变化与主题设计

## 变化的组织方式

构图/陈列关系来自 `bilibili-style-notes.md`（可选原始B站图）；默认绘制技法来自 `rendering-style.md` 对陈奕迅精选成品的文字校准，只继承画法，不继承颜色/陈设。明确用户画风优先。先把用户原封面仅做卡通化并锁定素材，再确定外部场景的共同画法、配色逻辑和主题，再用布局家族组织变化。各家族都应用 `spatial-composition.md` 的近景、占幅、物体接触和集中留白规则，不将“变布局”误解为把产品缩小搬到另一侧。通常选3–5家族，按曲数缩减，不为每家族额外制作无交付用途的样片。

| 家族 | 构图与视角 | 文字与LOGO关系 |
| --- | --- | --- |
| A 立放陈列 | 唱片套在左，唱机下方或斜前景 | 标题右侧，LOGO选上方独立留白 |
| B 反向陈列 | 唱片套在右，唱机左下，重新绘制而非镜像 | 标题左侧，LOGO可左上或右上 |
| C 俯视桌面 | LP套与盘片对角排布，唱机局部入画 | 标题在干净桌面空区，LOGO可左下或上部 |
| D 局部特写 | 唱针、沟槽前景特写，唱片套仍可辨认 | 标题上方/侧面，LOGO选另一处负空间 |
| E 海报叠放 | 唱片套和露出的盘片形成中部组，唱机局部作边框 | 文字分上下或两侧，LOGO跟随剩余留白 |

不机械循环A/B/C。按歌名长度、可靠曲风信息、主题和节奏安排；相邻曲至少两项明显差异，小位移或轻微色差不算。重复家族也变视角、器材、唱片材质/标签、主题配饰或LOGO位置，避免同画面换字。

字体在专辑规划时按中文/拉丁/日文分别锁定唯一字族和字重，之后全专辑同脚本一致。主题影响最初选字，不能逐曲轮换；长标题调整字号或换行，不换字体、不横向挤压。频道“黑胶试听”固定思源黑体Heavy，与LOGO字形一样不参加逐曲变化。所有执行Agent共享同一typography.json与字形样张。

器材可轮换木质底座、银色直驱、深色简洁款及全景/侧面/特写。盘片可黑色、与专辑呼应的彩胶、透明质感。这是艺术化道具，不是实际发行彩胶或歌手使用器材的事实声明，不添加型号、价格或版本断言。

LOGO使用 `assets/channel-logo.png` 透明成品，不再抠图或重绘；可换位置，不换色、不换字形，约5%内缩，不挡脸/歌名，避开右下时长区。需要保护对比时加中性留白/底衬，而不是改主题色。

## 主题适配

接受自然语言主题，无需用户填表。转化成场景、字体、器材年代感及2–3种核心配饰；画法按独立输入解析，主题不自动替换默认绘制技法，配色仍须遵守来源规则。全专辑共同主题，每曲只选部分并变组合，不每张塞满符号。

| 主题 | 设计方向 | 避免 |
| --- | --- | --- |
| 圣诞 | 复古节日唱片海报；当前专辑色优先，仅明确要求圣诞配色时扩展红/绿/奶油色；冬青/松枝、小灯串、礼物唱片套 | 变成礼品广告、LOGO换色 |
| 万圣节 | 当前唱片色优先；按封面选择月夜、墓园剪影、幽灵舞台、雾中唱片等新场景及少量南瓜/蝙蝠；不默认室内 | 自动橙紫调、旧架子音箱功放保留后只添南瓜、默认血腥 |
| 歌手纪念 | 档案/典藏质感、收藏唱片陈列、纸质标签、经核实的生涯视觉线索 | 擅自认定已逝、虚构周年日期或签名 |
| 其他节日 | 依指定文化挑选少量有意义图案或配饰，融入音乐场景 | 混用无关节日符号 |
| 爵士 | 蓝调/暖棕印刷、衬线或凝练海报字、木质唱机；语境支持时用乐器细节 | 仅凭歌名断言曲风或演奏配置 |
| City Pop / 80年代 | 时代字体、复古印刷、银色器材、少量网格/几何形态 | 无差别霓虹，每首都同一网格海报 |
| 摇滚/朋克 | 强轮廓、拼贴插画、粗黑/手写展示字、唱片贴纸与音乐海报边饰 | 遮字、篡改品牌、添加广告文案 |
| 其他时代 | 时代感器材轮廓、印刷纹理、版式和字体 | 把道具当真实版本、冒称精确历史复原 |

无主题时专辑色为主、音乐配饰为辅，不默认加植物、吊灯或沙发。有主题时重新选择场景、配饰和插画细节；只有明确配色指令才扩展/覆盖专辑色，不根据节日或曲风标签自动加入惯常颜色。每次先列本次允许场景物，不把音乐器材列表当必需清单。主题不自动增加图中文字，必需文案仍为歌手、曲名、黑胶试听，不额外添加专辑名，原专辑图内已有文字保留。

“纪念”不等于悼念。未说明时采用收藏/致敬感，不自动加遗像、黑纱、蜡烛或生卒年。具体周年或历史信息先核实，缺事实可省略；只有主题意义无法判断且实质影响设计才询问。

## 设计计划

`design-plan.json` 记录专辑级主题（可为空）、配色依据（各色来源、主辅面积、区域、允许/禁用色）、全新场景、主体占幅、前中后景及接触关系、集中标题区、主题空间锚点、允许道具和排除道具、实际生成输入文件列表、插画处理、已锁定脚本字体映射及typography.json路径；每曲记录全专辑连续 `sequence`、原始 `disc`、`track`、`title`、`layout_family`、`viewpoint`、`record_design`、`turntable_design`、`props`、`typography_id`、`caption_style`、`logo_position_by_ratio`、`differences_from_previous`。这是每次输出记录，不写回Skill成为固定歌单。

最后整体比较，避免每张单看合格、连看只是改字；变化不能牺牲准确文字、原色LOGO、专辑识别和醒目黑胶试听。

## 专辑图内部不参加变化

家族A–E只改变整张卡通化唱片套在缩略图中的位置、透视及周围元素；不能重设计专辑图内部。字体只在专辑开始时统一选定，歌手/歌曲同脚本全专辑使用同一套，黑胶试听使用频道固定字体；不重排原图自带文字。万圣节等主题可以改场景，不能把歌手变成怪物、把原封面换成月亮或用新姿势重画人物。最终PNG与ZIP放在指定黑胶封面根目录的专辑名目录，按比例平铺连续编号；设计记录与素材在成品目录之外的任务工作目录，见SKILL.md。

## 三类文字统一大小

所有家族统一“黑胶试听最大 > 曲名 > 歌手”：曲名短12–14%H、长8–12%H、下限8%；频道四字目标曲名1.3–1.6倍、默认1.4倍，最低max(12%H, 曲名1.25倍)、最高22%；歌手目标曲名45–65%、最多70%，硬范围4.5–9%H。仍检查曲名整段高度/面积、全组高度及安全边距，不把独立字号合格当整体合格。保留候选字族与频道固定字体，空间不够先换布局/减装饰，不降频道为同高小字。

## 唱机播放不可省略

所有构图家族、主题和两种比例均须满足SKILL.md的完整播放关系。A/B/E的机身可适当裁边，C俯视也需看到盘片实际在转盘上及唱臂/唱头落点，D特写必须保留足够机身/转盘线索证明是唱机上播放而不是孤立盘片。若构图不能同时保留完整专辑图、播放关系和大字标题，应重新排版，不得省略唱机。每曲设计计划记录可见播放区域，每个子任务将这条作为必选项，不自行降为可选道具。
